## Priorisierte Einreichungslogik 2026

1. **Q2:** aws Preseed + FFG (frühe F&E/Pilot-Bausteine sichern)
2. **Q3:** aws Seedfinancing + aws Fertigungsüberleitung (Skalierung + Industrialisierung synchronisieren)
3. **Q4:** aws ERP-Darlehen (investive Skalierung/Capex absichern)

- **AP1 Software EMS/Optimierung:** Preseed, Seedfinancing, FFG stark priorisieren

- **AP3 Hardware-Industrialisierung/Assembly:** Fertigungsüberleitung, FFG, ERP-Darlehen priorisieren  
- **AP4 GTM/Partneraufbau:** Seedfinancing primär; Preseed/Fertigungsüberleitung ergänzend  
- **AP5 Compliance/Regulatory:** FFG primär; Seed/Fertigungsüberleitung/ERP flankierend
